# Telegram Smart Dice & Slot Bot 🎲🎰

یک ربات خودکار و هوشمند با پایتون برای ارسال تاس و اسلات در تلگرام و دریافت خودکار جایزه با استفاده از پردازش تصویر و پیکسل (Pixel Color Detection).

## 🌟 ویژگی‌ها (Features)
- **اسکن ایمن محیط (Safe Scan):** تشخیص هوشمند بسته شدن گروه (قفل شدن) از طریق مانیتور کردن آیکون گیره چت (Attachment Clip) برای جلوگیری از کلیک‌های اشتباه.
- **مدیریت زمان و Cooldown:** رعایت دقیق محدودیت ۶۰ ثانیه‌ای تلگرام برای جلوگیری از مسدود شدن و اسپم.
- **دریافت خودکار جایزه (Auto Claim):** دابل-کلیک (Double Click) خودکار روی اعداد برنده پس از مچ شدن آن‌ها.
- **رفرش خودکار (Auto Refresh):** استفاده از کلید F5 برای آپدیت وضعیت مینی‌اپ پس از پایان انیمیشن‌ها.

## 🛠 پیش‌نیازها (Prerequisites)
- Python 3.x
- Telegram Desktop (نسخه ویندوز یا مک)
